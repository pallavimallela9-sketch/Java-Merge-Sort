# Merge Sort

A Java program to sort an array using the Merge Sort algorithm.

## Features

- Takes array elements from the user
- Divides the array into smaller parts
- Merges the elements in sorted order

## Technologies Used

- Java
- Arrays
- Scanner

## Concepts Used

- Arrays
- Recursion
- Divide and conquer
- Merge Sort

## Output

Sorted array: 10 20 30 40 50
